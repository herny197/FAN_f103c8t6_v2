# FAN_f103c8t6_v1 风扇控制工程

STM32F103C8T6（LQFP48），HAL + CMSIS-RTOS2 / FreeRTOS，Keil ARMCC 5。硬件参考“风扇2”；当前PADS接线中的LED7/R76对应程序的第五路LED，即PB1。

## 当前实现的功能

- 默认任务在业务循环之前调用一次 `user_Init()`，读取内部Flash恢复目标转速，初始化业务并放行其他任务。上电自动运行；没有有效记录时默认600 RPM，不立即写入默认值。
- 编码器顺时针升速，逆时针降速，每格100 RPM，目标范围0～1500 RPM。TIM2硬件完成A/B正交计数，任务读取计数差。方向按用户报告的板上结果反转，每格计数仍为调试值。
- 按键稳定30ms后切换启停，一次按压只触发一次。停止立即灭灯并锁定旋钮，目标保留；再次按下恢复原目标。停止期间仍消费计数并清半格，消息代次防止暂停旋转在恢复后重放。
- 旋钮调到0档时直接请求风扇端0% PWM，继续顺时针转动可升速。
- LED按目标值从LED5、LED4、LED3、LED2到LED1累计点亮，低电平有效。0～299不亮，300～599只亮LED5，600～899亮两灯，900～1199亮三灯，1200～1499亮四灯，1500五灯全亮。按键停机或保护停机立即灭灯。
- TIM3下降沿输入捕获测量TACH。中断只记录周期及序号，RPM在任务中换算；首个边沿、过捕获、无脉冲超时及跨Flash擦写样本不作为有效反馈。
- 正常调速使用新有效反馈，PWM最短调整间隔为100ms，每步最多2个百分点，闭环死区为±30 RPM。软启动每步最短200ms，从0%小步升速。启动最长12秒无有效测速时请求0%，待再次按键启动。
- 切换时以最新有效实测为起点，每个中间档最多推进100 RPM。达到相邻档中点即可推进，例如400→600先追踪500，实测到450时推进600。降速按反方向判定。有效反馈持续未通过某中间档的中点时，最多等待5秒便改为追踪最终目标。
- 启动或换档后，内部追踪最终目标且有效反馈进入最终目标±50 RPM时转入稳定状态。600 RPM档的稳定入口为550～650 RPM。只在稳定状态监测转速超差，允许范围取±100 RPM与±10%中较宽的一项。有效反馈连续越界满2秒后走普通减速停机，保留目标并记录 `FAN_FAULT_SPEED_DEVIATION`。重新进允许范围或收到无效样本时清除超差计时。再次按旋钮按键可恢复运行。
- 停止先降一步，至少等待200ms，并等到调整后完整新周期显示转速下降至少10 RPM才继续下一步；一步等待满1秒仍无有效下降则立即请求风扇端0%，记录异常。减速中再次按键可取消减速，从当前输出追踪保留目标。
- 运行时每次旋转重置静止计时；静止满3秒且目标与已保存值不同，发起一次保存。持续静止不重复保存，转回已保存值不写入；失败不周期重试，下一次旋转后才可再尝试。
- Flash采用双页追加日志，含版本、序号、目标反码、CRC16及最后写入的提交标志。换页时保留上一有效页，拒绝半写和损坏记录。掉电可能丢失尚未提交的新设定，启动恢复最近有效记录。

## 任务及模块

| CubeMX任务 | 用户入口 | 职责 | 等待 | 原有栈 |
|---|---|---|---|---|
| defaultTask | My_Task1 | user_Init、控制状态、测速消费、唯一运行时PWM输出 | 约10ms | 128 words / 512字节 |
| myTask02 | My_Task2 | 编码器累计计数读取、按键去抖、输入事件生产 | 约5ms | 256 words / 1024字节 |
| myTask03 | My_Task3 | 目标灯条、唯一运行时Flash写入 | 约20ms | 256 words / 1024字节 |

任务数量、优先级、栈和8192字节RTOS堆未改变，不需要为本轮增加CubeMX任务。输入使用静态队列；Task1独占控制状态，通过短临界区快照发布。初始化完成前其他任务阻塞等待；实际Flash擦写不放在全局长临界区内。

- `Core/Src/user_work.c`：任务组织、就绪门控、输入启停代次和保存同步。
- `Core/Src/fan_control.c`：与硬件无关的状态机、LED阈值和一次性保存资格判定。
- `Core/Src/fan_io.c`：硬件编码器、按键、TACH、反相PWM和LED输出。
- `Core/Src/fan_settings.c`：双页设置日志与校验。
- Keil调试可用 `g_fan_status` 查看最终目标 `control.target_rpm`、当前追踪档位 `control.control_target_rpm`、实际测速 `measured_rpm`、风扇端占空比 `control.duty_permille` 和故障位 `control.faults`。

## 引脚与调试参数

| 功能 | 当前配置 |
|---|---|
| PWM | PA8 / TIM1_CH1，72MHz、PSC=0、ARR=2879，计算25kHz |
| NPN反相 | 风扇端0%对应MCU持续高、CCR1=2880；风扇端100%对应CCR1=0 |
| 编码器 | PA0/PA1 / TIM2，TI12。默认4计数/机械格，方向系数−1 |
| 按键 | PB0，外部上拉，按下低电平 |
| TACH | PA6 / TIM3_CH1，PSC=7199，每计数0.1ms；暂按每转2脉冲 |
| LED1～5 | PB12、PB13、PB14、PB15、PB1，低电平亮；GPIO生成初值为高、灯灭 |
| HAL / RTOS时基 | HAL使用TIM4，RTOS节拍1000Hz |

停止保持PWM通道工作，不调用 `HAL_TIM_PWM_Stop()`。风扇端0%只是请求，不能据此认定实物已停。TACH每转脉冲数、编码器每格计数、方向、最低启动/稳定转速及控制响应都需要实测，尤其不保证100/200 RPM能够稳定运行。

## Flash区域与重新生成

正式64KB Flash末尾两个1KB页专用于设置：

- 页0：0x0800F800～0x0800FBFF。
- 页1：0x0800FC00～0x0800FFFF。
- Keil程序区：起点0x08000000，大小0xF800（62KB）。

Keil工程已登记三个新增.c，并缩小IROM与OCR_RVCT4程序区。重新生成后必须复核这两个限制、三个模块登记、user_work登记和既有任务调用；不能让代码覆盖数据页。下载时若执行全片擦除，历史设置也会丢失，此后按无有效记录恢复默认600 RPM。

本轮未改.ioc、生成的外设初始化、任务创建或中断入口。新增HAL_TIM_IC_CaptureCallback只在fan_io.c定义一次。

## 验证边界

2026-11-08版通过沙箱外临时工程的完整Keil编译和链接，0错误、0警告。链接生成的HEX数据末地址为0x08005CD7，设置区从0x0800F800开始。静态调用图给出的Task1、Task2、Task3最大调用深度分别为180、216、284字节。板上栈高水位待测。

控制器主机测试位于 `tests/test_fan_control.c`，覆盖目标和显示档位、0档、分段升降速、切换超时、稳定入口、连续超差停机、重新启动、静止保存和计时回绕。Flash模块此前已通过528个模拟断电位置及损坏恢复测试。

用户已烧录上一版并反馈旋钮方向、亮灯顺序、0档和调速响应。本次修订的板上复测包括旋钮方向、LED5先亮、0档时风扇第4脚电平与实际停转、TACH每转脉冲数以及切换和稳定时的调速表现。控制步长、周期、误差带和超时为可调初值。

本版烧录文件为 `MDK-ARM/FAN_f103c8t6_v1/FAN_f103c8t6_v1_20261108.hex`。使用日期区分新版固件。
